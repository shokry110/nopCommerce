﻿sarayetel: free and open-source eCommerce solution
===========

[sarayetel](https://www.sarayetel.com/?utm_source=github&utm_medium=content&utm_campaign=homepage) is the best open-source eCommerce platform. sarayetel is free, and it is the most popular ASP.NET Core shopping cart.

![sarayetel demo](https://www.sarayetel.com/images/github/responsive_devices_codeplex.png#v1)

### Key features ###

* The product is being developed and supported by the professional team since 2008.
* sarayetel has been downloaded more than 3,000,000 times.
* The active developer community has more than 250,000 members.
* sarayetel runs on .NET 9 with an MS SQL 2012 (or higher) backend database.
* sarayetel is cross-platform, and you can run it on Windows, Linux, or Mac.
* sarayetel supports Docker out of the box, so you can easily run sarayetel on a Linux machine.
* sarayetel supports PostgreSQL and MySQL databases.
* sarayetel fully supports web farms. You can read more about it [here](https://docs.sarayetel.com/en/developer/tutorials/web-farms.html?utm_source=github&utm_medium=referral&utm_campaign=documentation&utm_content=text).  
* All methods in sarayetel are async.
* sarayetel supports multi-factor authentication out of the box.
* Start our [online course for developers](https://sarayetel.com/training?utm_source=github&utm_medium=referral&utm_campaign=course&utm_content=text) and get the practical and technical skills you need to run and customize sarayetel websites.

![Logo](https://www.sarayetel.com/images/github/logos.png#v2)

sarayetel architecture follows well-known software patterns and the best security practices. The source code is fully customizable. Pluggable and clear architecture makes it easy to develop custom functionality and follow any business requirements.

Using the latest Microsoft technologies, sarayetel provides high performance, stability, and security. sarayetel is also fully compatible with Azure and web farms.

Our clear and detailed [documentation](https://docs.sarayetel.com/developer/index.html?utm_source=github&utm_medium=referral&utm_campaign=documentation&utm_content=text) and [online course](https://sarayetel.com/training?utm_source=github&utm_medium=referral&utm_campaign=course&utm_content=text) for developers will help you start with sarayetel easily.


### The advantages of working with sarayetel ###

sarayetel offers powerful [out-of-the-box features](https://www.sarayetel.com/features?utm_source=github&utm_medium=referral&utm_campaign=features&utm_content=text) for creating an online store of any size and type.

sarayetel is integrated with all the popular third-party services. You can find thousands of integrations on sarayetel [Marketplace](https://www.sarayetel.com/marketplace?utm_source=github&utm_medium=referral&utm_campaign=marketplace&utm_content=text).

The [Web API plugin](https://www.sarayetel.com/web-api?utm_source=github&utm_medium=referral&utm_campaign=WebAPI&utm_content=text) by the sarayetel team lets you build integrations with third-party services or mobile applications using REST. The Web API plugin is available with source code and covers all methods of sarayetel: backend and frontend. You can read more about it [here](https://www.sarayetel.com/web-api?utm_source=github&utm_medium=referral&utm_campaign=WebAPI&utm_content=text).

Friendly members of the [sarayetel community](https://www.sarayetel.com/boards?utm_source=github&utm_medium=referral&utm_campaign=forum&utm_content=text) will always help with advice and share their experiences. sarayetel core development team provides [professional support](https://www.sarayetel.com/sarayetel-premium-support-services?utm_source=github&utm_medium=referral&utm_campaign=premium_support&utm_content=text) within 24 hours.
